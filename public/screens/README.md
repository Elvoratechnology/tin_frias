# Project Fallback Screenshots

This directory contains static screenshots displayed when the live iframe preview of a project fails to load or is blocked by third-party iframe embed restrictions (e.g. `X-Frame-Options` or Content Security Policy headers).

## Screenshot Files:
1. `worklane.png` — Screenshot for **Worklane** (1280x800 recommended)
2. `inky.png` — Screenshot for **Inky** (1280x800 recommended)
3. `resiboss.png` — Screenshot for **Resiboss 2.0** (1280x800 recommended)

To update them, simply drop your full-screen browser screenshots of each project into this `/public/screens` folder with the names above.
